The catalog

Grouped by the practice that uses it most. Most engagements combine two or three.

Security

Security Toolbox

A self-hosted security console with thirty-seven tools across discovery, exposure, breach checks, threat intelligence, OSINT, local network inventory, forensics and encryption.

Enterprise benefit
One place for the everyday checks your security team runs by hand today, with keys held server-side and results that can be filed.
Integrates with
Shodan, NVD, VirusTotal, AbuseIPDB, GreyNoise, certificate logs, your SIEM via export, nmap and arp-scan on the host.

PassPass credential vault

A credential vault and token authentication service with a REST API, built for teams whose automations need secrets as much as their people do.

Enterprise benefit
Ends shared spreadsheets and chat-pasted passwords. Tokens are issued, validated and revoked through one audited service.
Integrates with
CI pipelines, automation runners, AWS deployment, any service that can call a REST endpoint.

Engineering

Codebase Scorecard

A zero-dependency dashboard that grades any repository A to F across fifteen quality and security dimensions and, where allowed, drafts the fixes.

Enterprise benefit
A single objective score for every repo in the estate, with file and line for each finding. Useful for audits, acquisitions and quarterly reviews.
Integrates with
GitHub, GitLab and any Git host; CI as a gate; OSV and NVD for vulnerabilities; optional AI-assisted remediation.

System Otel

An OpenTelemetry-native observability engine: one drop-in agent, one engine binary you own, one live dashboard for logs, traces, metrics and build events.

Enterprise benefit
Observability for teams that cannot justify or cannot allow a SaaS monitoring suite. No data leaves the network.
Integrates with
Any language over OTLP, build and compile pipelines, Python first with more agents on request.

FrostDeck test studio

A web-based Playwright studio for ServiceNow and similar enterprise UIs: live browser streaming, action recording with resilient locators, page element maps and one-click runs.

Enterprise benefit
Regression coverage for platforms that never had it, with locators that survive upgrades so the suite stays alive after we hand it over.
Integrates with
ServiceNow instances, Playwright and Robot Framework, CI runners, your existing Selenium, ATF and Playwright scripts via conversion.

Test script converter

Translates Playwright, Selenium, ATF and free-form test scripts into one maintained Robot Framework suite, with a confidence-tagged migration report for every file.

Enterprise benefit
Years of scattered test scripts become one framework your team can run in CI, without rewriting them by hand.
Integrates with
Your existing test repositories, Robot Framework runners, CI, and the test studio above. Exposed over REST and MCP for headless use.

Platform mappers

Per-platform analysis engines for Salesforce, ServiceNow, Workday, Conga and Veeva: dependency maps, field conflicts, code red flags, schema health and a modernisation backlog, each with a native report. A meta-mapper runs every engine in parallel from one set of connections.

Enterprise benefit
Upgrade and breakage risk scored in minutes before anyone writes a test, and a governance report leadership can act on.
Integrates with
Live orgs over OAuth or session auth, with a simulate mode when a connection is not yet approved. ServiceNow adds AI explanation, coverage and test generation.

MapOps desktop

The mapper engines packaged as a self-contained desktop app with its own encrypted connection portal, in-app pulls, downloadable report bundles and a field-mapping studio. An admin build provisions and controls a fleet of them.

Enterprise benefit
Analysts and field teams run platform analysis with nothing installed and no server to stand up. Secrets never leave the machine.
Integrates with
Salesforce, ServiceNow, Workday, Conga, Veeva, GitHub, GitLab and Jira pulls, on macOS and Windows.

Connection Fabric

A central portal and service that connects SaaS platforms, holds credentials in an encrypted vault, links records across systems and runs automations such as a case in one system creating a linked incident in another.

Enterprise benefit
Cross-platform workflows without another integration platform licence, embeddable in your own products through its REST API.
Integrates with
ServiceNow, Salesforce, Workday, Jira, GitHub, GitLab, Slack, Conga and Veeva through a pluggable adapter framework.

Migration console

A record migration console that recommends field and value maps, understands module modes such as ITSM, CMDB and CPQ, scopes by batch, percentage or filter, and runs dry-run, upsert and rollback with a project split plan and runbook.

Enterprise benefit
Platform consolidations and cross-system moves with a rehearsal, a rollback and a runbook, instead of a weekend and a prayer.
Integrates with
Connection Fabric connections, including cross-platform moves such as ServiceNow or Salesforce into Jira.

Smosher compression

Content-defined chunking, content-addressed deduplication and zstd compression into bundles with a rebuild graph, optional encryption, delta receipts for data feeds and a live monitor.

Enterprise benefit
Large exports, backups and evidence bundles shrink and ship with proof of what changed since last time.
Integrates with
File systems, data feeds and output routes you define, with a streaming monitor for operators.

Unified toolbox portal

One web shell that hosts every tool above as a self-contained module: a single sign-in, shared settings and accessibility options, a documentation hub and a guided tour for new users.

Enterprise benefit
Your teams get one portal instead of a dozen bookmarks, and each module can be lifted into another product with minimal surgery.
Integrates with
Your identity provider, your logging, and any of the tools in this catalog.

AI

Agent Performance Lab

A QA sandbox for AI agents: prompt library with expected answers, parallel multi-agent runs, manual scoring on six dimensions, baselines, trends and scorecards. An evaluator spins up isolated test workspaces and runs a golden scenario corpus repeatedly against candidate agents.

Enterprise benefit
Proof that the agent got better, not worse, after every change. The scorecard is readable by leadership and defensible to audit.
Integrates with
Any agent with an HTTP endpoint, your test corpus from spreadsheets, CI for regression gates.

Grounded AI console

A chat console that answers from your documentation and acts on your live systems through governed connections, exposed as a REST API and an MCP server.

Enterprise benefit
An internal copilot that reads your real data with read and write governance, egress guards and per-run telemetry, instead of a public chatbot with a prompt.
Integrates with
Claude and other models, Connection Fabric for live systems, your documentation via capture to Markdown, any MCP-capable client.

AI usage and billing simulator

A fixed-seed traffic simulator that compares metering models across customer sizes and time horizons, producing self-contained HTML and PDF reports.

Enterprise benefit
Price or package an AI feature with numbers instead of guesses. See which customers run out of allowance and when, before the contract is signed.
Integrates with
Your usage exports, your pricing assumptions, your board deck.

Leadership

Executive dashboards

Self-contained dashboards for the executive, the team and the system: KPIs, usage, agent scorecards and support case analysis, each with a legend that explains every number.

Enterprise benefit
Reports that get read because the calculation is on the page. One file, no login, prints cleanly for the board pack.
Integrates with
CSV and spreadsheet exports from your ticketing, HR and usage systems, rebuilt on a schedule.
