# Log Explorer

A Pen created on CodePen.

Original URL: [https://codepen.io/editor/m0b015w/pen/01a17500-5588-7df0-8b69-1b6ad2334941](https://codepen.io/editor/m0b015w/pen/01a17500-5588-7df0-8b69-1b6ad2334941).

A log investigation workspace for security and SRE teams working the same incident. Search six hours of logs in Lucene or LogQL, and switch languages with a preview of what each clause becomes. Group lines into patterns, compare a spike to the time around it, and follow an IP or user across every service. Pin evidence to a case along with the query that found it, write alert rules in either language, and watch a live tail as a second attack wave arrives.

It uses TypeScript, React, TanStack Query, D3, and GSAP.
